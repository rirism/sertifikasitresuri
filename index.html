Generator Lampiran Surat Teguran

Excel → ZIP berisi 1 PDF per instansi (1 s.d. 4 tabel sesuai data). Semua proses berjalan di browser, tidak ada data yang dikirim ke internet.

0. Persiapan

Cara memasang font (buka bila font belum terpasang)
Cara 1 — permanen, sekali saja untuk semua pengguna folder ini:
Buka pasang-font.html di folder yang sama, pilih kedua file font, lalu simpan file fonts.js yang terunduh ke dalam folder lib. Setelah itu halaman ini memakai font tersebut otomatis.

Cara 2 — cepat, hanya untuk browser ini:
Frutiger 45 Light (teks biasa)
Frutiger 65 Bold (judul & nama instansi)
